# Pillow Creek

Tienda online de equipamiento, indumentaria y accesorios para
camping y actividades al aire libre.

## Descripción

Pillow Creek es un proyecto de desarrollo web que consiste en crear
una tienda online especializada en productos para camping y outdoor.

La tienda reúne diferentes categorías de productos, como zapatillas,
camperas, carpas, linternas y sillas de camping, con el objetivo de
ofrecer una experiencia de navegación clara, visual e intuitiva.

El proyecto busca representar la identidad de la marca mediante un
diseño funcional, una presentación ordenada de los productos y una
experiencia adaptable a distintos dispositivos.

## Objetivos

- Diseñar una interfaz visual coherente con la identidad de Pillow Creek.
- Organizar los productos en categorías.
- Facilitar la exploración del catálogo.
- Desarrollar una navegación intuitiva.
- Crear un diseño responsive para computadoras, tablets y celulares.
- Incorporar funcionalidades de comercio electrónico de forma progresiva.

## Tecnologías utilizadas

- HTML5: estructura y contenido del sitio.
- CSS: estilos y diseño visual 

## Categorías de productos

- Calzado outdoor: zapatillas para actividades al aire libre.
- Indumentaria: camperas y prendas para camping.
- Carpas: equipamiento para descansar y refugiarse.
- Iluminación: linternas y accesorios de iluminación.
- Mobiliario outdoor: sillas de camping.
- Accesorios: otros productos relacionados con camping y aventura.
