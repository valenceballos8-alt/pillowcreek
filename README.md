# PILLOW CREEK

Sitio responsive HTML + CSS. Abrir index.html con Live Server.

## Imágenes
Copiar las imágenes originales a `assets/`, respetando los nombres de `AGREGAR-IMAGENES.txt`.

## Responsive
Mobile-first sin media query; tablet desde 768px; desktop desde 1024px. Grid con áreas semánticas en inicio, productos, nosotros y contacto.

## Formulario
El formulario es una demostración sin backend. No envía correos.

## Entrega
Revisar enlaces e imágenes en Live Server, verificar tamaños 375px, 768px y 1280px, subir el repositorio a GitHub y configurarlo como público.
